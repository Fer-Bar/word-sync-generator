Maintainers may distribute a prebuilt private wheel; no public publication is authorized. "no veo necesario tests aca, si es para algo web, o sea tests para un cuaderno notebook": do not add a notebook-cell/UI test suite; validate the notebook by actual execution and browser interaction, retaining engine/CLI regression coverage.
- **S7:** "pero no ves conveniente que con la cli probemos que el \"motor\" o operaciones basicas funcionen? porque lo demas serian inputs o cosas mas visuales, igual te autorizo, ve la mejor manera de avanzar" Validate shared operations through CLI-driven Colab execution and separately check notebook interactions. Authorized remote scope: use the CLI's configured OAuth credentials to create a dedicated Google Colab test session, upload package/notebook and authorized test audio, run checks, download results, and close only that session; do not mount Drive or touch other sessions.
